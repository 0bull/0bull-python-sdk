## Claude Code

Skills are namespaced by plugin: `agent-skills:spec-driven-development`, `open-code-review:delegate-review`. The lifecycle commands map to phases: `/agent-skills:spec` → `/agent-skills:plan` → `/agent-skills:build` → `/agent-skills:test` → `/agent-skills:review` → `/agent-skills:code-simplify` → `/agent-skills:ship`.
